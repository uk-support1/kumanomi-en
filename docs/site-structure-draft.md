## 第1稿仕上げ（2026-09-02）での確認事項

**ヘッダーロゴ（透過PNG）について**
- クライアントの想定と異なり、リポジトリ内の`クマノミ園　ロゴのみ.png`は透過PNGではなく、白背景が全面に敷かれた不透明画像であることをピクセル検証で確認（全体をサンプリングしAlpha値が常に255＝不透明）。
- 実際に透過（Alpha値0〜255が混在）していたのは`ChatGPT Image 2026年9月2日 09_11_43.png`のみ。ただしこのファイルは「グループホーム クマノミ園」の文字を含まず、魚＋花びらのアイコン部分のみ。イラストの意匠（色・形）は正式ロゴと同一に見えるが、ファイル名から生成AIで作成されたものである可能性が高く、正式な納品データそのものではない可能性がある。
- 上記を踏まえ、今回はこのアイコンをヘッダーに使用し、消えた文字部分を補うため`グループホーム クマノミ園`のテキストをアイコン横に追加した。
- → クライアントに、この透過アイコンが「正式ロゴのデータとして使ってよいものか」をご確認いただきたい。正式な透過版（アイコン＋文字）が別途あれば差し替え可能。

**住所表記の揺れ**
- 依頼文中の住所表記は「コーポYANAGI」（アルファベット）。サイト・パンフレット記載は「コーポヤナギ」（カタカナ）。
- 今回はサイトの既存表記（コーポヤナギ）を変更せず維持。表記としてどちらが正式か確認をお願いしたい。

**Googleマップの位置確認**
- 住所（奈良市般若寺町281-1）でGoogle検索したところ、候補が複数出ることはなく単一の建造物として一意に解決された。
- 実際に地図を目視したところ、パンフレット内の簡易地図に記載されていたランドマーク（コンビニではなく道路の「754」ルート番号標識、「旧・奈良監獄」、「般若寺」）が、ピンの位置周辺に確認でき、パンフレットの地図と整合していることを確認した。
- ただし、建物の入口・部屋番号レベルの精度までは確認できないため、最終的な位置の正確性はクライアント側でも一度ご確認をお願いしたい。

**将来の独自ドメイン移行時に必要な変更**
- お問い合わせフォームの送信後リダイレクト先（`_next`）は現在`https://uk-support1.github.io/kumanomi-en/?sent=true#contact`固定（[index.html](../index.html)内`<input type="hidden" name="_next" ...>`）。
